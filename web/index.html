How to use

  • Available letters: type the letters you have and press Enter. Use ? or * for a blank/wildcard. Leave empty to browse every word.
  • Show: pick which unit types to list: towers, harvesters and mods.
  • Sort by: switch between value (points or the chosen stat) and alphabetical.
  • Stat chips above the results filter to words that boost that stat, and sort by it. Pick several to rank by a combined score.
  • Contains / Starts / Ends / Length / Effect narrow the list further. In order means the letters must appear together in that order; Exact amount means exactly that many of each letter.
  • Clever mode lists combinations of words that use every available letter.
  • Click a word to see all its stats. USE copies the word and removes its letters from your available letters. DEF looks up the definition. ♡ saves it as a favorite.
